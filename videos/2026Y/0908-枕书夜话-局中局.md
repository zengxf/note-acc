# 局中局
- https://www.youtube.com/watch?v=d8Nern1L1ts
- `枕书夜话 2026-09-08 13:00:23`


#### ‌持满者与天，定倾者与人，节事者以地
- **当你事业达到顶峰、一切圆满的时候，要效法天道，做到盈满却不溢出、强盛却不骄纵，不居功自傲，才能守住这份成果**；
- **当身处危难、局面濒临崩溃的时候，要放低姿态顺应人心，谦卑待人、争取各方支持，才能凝聚力量力挽狂澜**；
- **处理日常事务、生产经营时，要因地制宜、节制有度，像大地承载万物那样顺应客观条件，不违农时、合理利用资源，稳步把事情做好**。

**这句话的底层逻辑是**
- **在任何极端情况下，都不要被情绪劫持，要用理性看清楚自己当下的处境，然后做出最符合长期利益的选择**。
- 投降在当时所有人看来是最屈辱的选择，但范蠡看到的不是屈辱。
- 他看到的是吴国现在处于极盛状态，骄兵必败；越国现在处于极弱状态，哀兵必胜。
- 时间是站在越国这边的，只要能活下去，就有翻盘的机会。
- **这就是格局，这就是在局中看局的能力**。
- ***普通人在极端压力下只能看到眼前的困境；而顶级的战略家，在极端压力下看到的是未来十年的棋局***。



#### 飞鸟尽，良弓藏；狡兔死，走狗烹。
**越王为人，长颈鸟喙，可与共患难，不可与共乐**。
- 翻译成现代话就是：**当你的利用价值消失之后，你的主人会把你当成威胁，然后消灭你**。

**用现代职场逻辑来看**：
- **在公司创业阶段，老板需要你，你是核心资产；但当公司上市了、做大了，老板不再需要你的时候，你的处境和文种是一样的**。
- **普通人赢了会沉浸在喜悦中，而真正的强者在赢了的那一刻，已经开始思考下一个危险在哪里**。




#### 四个可以直接用于现代生活的底层逻辑
1. **永远不要在对手最强的时候正面硬刚。**
    - **当你的对手处于权力巅峰，当环境对你不利时，正面对抗是最愚蠢的选择**。
    - 你需要等待，但**等待不是消极，而是积蓄**。

2. **功成之后必须知道什么时候该退。**
    - **历史贡献是过去式，老板看的永远是现在和未来**。
    - **当你的存在从资产变成负债时，你必须调整位置：要么主动退出，要么主动降低存在感，要么找到新的价值创造点**。

3. **在极端压力下保持对全局的清醒认知。**

4. **看人比看事更重要。**
    - **在任何博弈、竞争、合作中，最关键的变量永远不是规则、资源、技术，而是人**。
    - **看不懂人，再好的规则和资源，也会被人性的弱点吞噬**。
